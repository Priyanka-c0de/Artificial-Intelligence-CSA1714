# Artificial Intelligence Lab — Assessments Repository

This repository contains assessment work for the Artificial Intelligence Lab course, organized by Unit and Assessment per faculty instructions.

Overview

Follow the course-provided folder structure and naming conventions so faculty can evaluate work easily and you can showcase projects later.

Repository structure (created by templates)

- README.md (this file)
- NAMING_CONVENTION.md — rules for filenames and examples
- UPLOAD_INSTRUCTIONS.md — how to upload via web or git
- templates/ASSESSMENT_README_TEMPLATE.md — template to use for each assessment
- Unit-1 .. Unit-5 — each unit contains three assessment folders (Assessment-1..3)
- Mini_Project/ — dataset, source code, images, documentation, presentation, demo video
- Assignments/, PPT/, Reports/, Datasets/, Source_Code/, Certificates/ — supporting folders

Quick usage

1. For every assessment, create a folder inside the appropriate Unit named exactly as:
   Assessment-<n>_<Short_Descriptive_Name
   Example: Unit-1/Assessment-1_Analytical_Problem_Solving

2. Put all related files in that assessment folder: Problem.pdf, Solution.pdf, Code (.py), Output images, Report.pdf, README.md (use the template in templates/)

3. Follow the naming conventions in NAMING_CONVENTION.md and use clear commit messages (examples in UPLOAD_INSTRUCTIONS.md).

If you want changes to template wording or different default software versions, tell me and I will update the files.
